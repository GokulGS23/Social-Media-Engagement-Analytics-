📊 Social Media Engagement Analytics

Overview

This project analyzes social media engagement data using Python. The goal is to understand how different factors such as post type, category, sentiment, country, and user characteristics affect social media performance.

The analysis includes data cleaning, exploratory data analysis, data transformation, statistical analysis, and visualizations.

Dataset

Dataset: "social_media_engagement_5000.csv"

The dataset contains information related to social media posts and engagement metrics, including likes, comments, shares, impressions, watch time, follower count, post type, post category, sentiment, device type, and engagement rate.

Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly

Analysis Performed

- Data loading and data type checking
- Missing value and duplicate handling
- Data cleaning and formatting
- Hashtag count extraction
- Engagement score creation
- Exploratory data analysis using Pandas
- GroupBy analysis by post type, country, and sentiment
- Statistical analysis of engagement metrics
- Correlation analysis
- Data visualization using Matplotlib and Seaborn
- Interactive visualization using Plotly

Visualizations

The project includes visualizations such as:

- Likes vs Impressions
- Daily Engagement Trend
- Posts by Category
- Gender Distribution
- Age Distribution
- Engagement Rate Distribution
- Post Type Distribution
- Average Likes by Post Category
- Follower Count vs Sentiment
- Correlation Heatmap
- Engagement by Device Type

Key Insights

The analysis helps identify:

- Which post types and categories perform better
- Countries with higher engagement rates
- The relationship between age and engagement
- Performance differences between verified and non-verified accounts
- The impact of device type on watch time
- Which sentiment categories perform better

«Note: The dataset contains posting dates but does not include posting time information, so the best time of day for impressions cannot be determined from the available data.»

Conclusion

This project demonstrates a complete Python data analysis workflow, from cleaning and exploring data to performing statistical analysis and creating visualizations to understand social media engagement patterns.
